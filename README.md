# La Doc

App de estudio de medicina, instalable en Android y pensada para funcionar sin internet. El brief completo está en [CLAUDE.md](CLAUDE.md).

## Desarrollo

```bash
npm install
npm run dev            # servidor local
npm test               # pruebas unitarias
npm run build          # versión de producción en dist/
npm run test:offline   # comprueba que la app abre sin internet (requiere build)
```
